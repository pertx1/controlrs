# El prompt de Pertx para que una IA te haga una web

Es el que se regala a quien comenta **WEB** (día 2) o **PROMPT** (día 5). Cópialo, rellena lo que va entre corchetes y pégaselo a Claude Code (o a la IA que uses).

```
Quiero una web de una sola página para un negocio. Antes de escribir código, enséñame un plan corto y espera a que te diga "adelante".

EL NEGOCIO
- Qué es: [tipo de negocio, por ejemplo una peluquería de barrio]
- Para quién: [quiénes son sus clientes]
- Qué vende o qué ofrece: [3–5 servicios o productos, con precio si lo hay]
- Qué tiene que hacer el cliente al entrar: [llamar / pedir cita por WhatsApp / ver la carta / ir al local]
- Tono: [cercano / elegante / divertido]

LA WEB
- Secciones, en este orden: portada con una frase clara + botón principal, servicios, fotos, opiniones, horario y mapa, contacto.
- Pensada primero para el MÓVIL.
- Botón principal: [Llamar / Escribir por WhatsApp / Reservar]. Que se vea siempre.
- Colores: [2 colores o "elige tú algo sobrio"]. Sin textos de relleno (nada de "Lorem ipsum"): si te falta un dato, pon [FALTA: ...] para que lo vea.

REGLAS
- Código sencillo (HTML, CSS y un poco de JavaScript), en archivos separados.
- Explícame qué archivo has creado y para qué sirve cada uno.
- Después de cada cambio que te pida, dime qué has tocado.
```

**Truco:** cuando la tengas, ábrela en el móvil y pide los cambios **de uno en uno** ("el botón más grande", "la foto de portada más oscura"…). Si le pides diez cosas a la vez, mezcla todo.
